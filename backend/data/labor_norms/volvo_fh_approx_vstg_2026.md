# Volvo FH Approx VSTG 2026

Файл: `volvo_fh_approx_vstg_2026.csv`

Назначение:

- стартовый импортируемый справочник нормо-часов для `Volvo FH`
- источник не OEM-выгрузка, а вручную собранный reference layer
- значения сведены к одному числу для системы, потому что текущая модель каталога хранит `standard_hours` как одно значение

Как рассчитаны часы:

- если в исходном описании был диапазон, в CSV записана середина диапазона
- округление сделано до `0.1` часа
- названия и алиасы подобраны так, чтобы справочник был пригоден для матчинга OCR-строк

Происхождение данных:

- пользовательский документ с расширенной таблицей `Volvo FH`, приближенной к логике `Volvo Standard Time Guide (VSTG)`
- дата фиксации в проекте: `2026-03-25`

Ограничения:

- это приближённый каталог для аналитики и предварительной сверки
- не использовать как единственный источник для претензионной, судебной или дилерской калькуляции
- для production-grade проверки по `VIN` нужен дилерский/OEM или лицензируемый labor time источник

Импорт в систему:

```bash
cd backend
./.venv/bin/python -m app.scripts.import_labor_norms \
  --path data/labor_norms/volvo_fh_approx_vstg_2026.csv \
  --scope volvo_fh_approx_vstg_2026 \
  --brand-family volvo \
  --catalog-name "Volvo FH Approx VSTG 2026"
```
