# Regression Baseline

Сюда сохраняются технические подтверждения перед ручной приемкой:

- targeted backend regression logs по report/export и employee workflow
- frontend build log
- `scripts/predeploy-usecase-check.sh` log
- краткая сводка в `summary.md`

Рекомендуемое наполнение можно собрать командой:

- `./scripts/collect-signoff-baseline.sh <run-folder-name>`
